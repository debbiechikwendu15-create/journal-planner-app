# A Journal For Girls 🌺

A beautiful, customizable journal and planning app designed specifically for girls. Write your thoughts, plan your days, and express yourself with your favorite colors!

## Features

✨ **Journal Entries** - Write and save your thoughts, feelings, and daily experiences
📅 **Daily Planner** - Organize your life with daily plans and upcoming schedules
🎨 **Customizable Themes** - Choose from 13+ beautiful color themes
💾 **Auto-Save** - Your entries are automatically saved locally
📱 **Responsive Design** - Works seamlessly on desktop and mobile devices
🔒 **Private** - All your data stays on your device

## Getting Started

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/debbiechikwendu15-create/journal-planner-app.git
   cd journal-planner-app
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Runs the test suite

## How to Use

### Journal
1. Click on the "Journal" tab
2. Enter a title and your thoughts
3. Click "Save Entry"
4. View all your previous entries below
5. Delete entries you no longer need

### Planner
1. Click on the "Planner" tab
2. Select a date from the calendar
3. Add your plans for that day
4. Check off completed tasks
5. View upcoming plans below

### Change Theme
1. Scroll to the footer
2. Click on any color theme button
3. Your preference is automatically saved
